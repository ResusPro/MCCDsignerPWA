Profile persistence
-------------------
- v0.8.1 stores the clinician profile in a private local JSON file (OPFS) where supported.
- The transparent PNG signature is embedded in that local JSON.
- IndexedDB remains as a backup/fallback.
- Persistent storage is requested where supported.
- Profile fields auto-save and are also saved when the app is hidden/closed.

Workflow
--------
- Final signed output generated without an additional watermark.
- Signed filename uses per-user initials: <original>-<initials>signed.pdf.
- Transparent PNG signature tested successfully.
- Desktop Incoming -> Signed + Archive workflow completed successfully.
- Seven live Incoming documents were subsequently processed successfully.
- Android individual-PDF picker -> review/sign -> Share workflow completed successfully.
- Narrow Medical Examiner boxes after automatic 90°/270° orientation are automatically widened while retaining detected vertical placement.

Safety behaviour
----------------
- Final output requires signer name, qualifications, GMC number and a PNG signature.
- JPEG signatures are rejected because an opaque background can obscure certificate text.
- Desktop workflow writes and SHA-256 verifies the signed PDF and archived original before removing the original from Incoming.
- Every generated PDF is shown for visual review before approval.
- No patient PDFs are included in this public repository.
