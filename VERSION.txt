MCCDSigner PWA v0.8.9

Workflow UI update:
- A complete signer profile now collapses to the green "Ready to sign as…" banner.
- The banner explicitly identifies the loaded signer and retains qualifications, GMC/signature confirmation and filename initials.
- "Change signer details" expands the full signer fields and signature controls.
- If any signer detail becomes missing or invalid, the full signer section expands automatically.
- The v0.8.8 compact local-workflow summary and oldest-first Incoming queue remain unchanged.

No detector, signing-coordinate, Edge compatibility, Android persistence or deskew logic changed.

ME spreadsheet shortcuts (revised 13 November 2026):
- Community, PGH and RBH open the corresponding NHS SharePoint spreadsheets in new tabs.
- No import or extra setup. PWA loads the central ME_Spreadsheet_Links.txt automatically on each page opening, with network-first service-worker handling and local fallback.
- Source file order: Community, RBH, PGH. Display order: Community, PGH, RBH.
- When the hosted links file is replaced at a quarterly refresh, the PWA uses those links automatically; changes to a PC-only copy do not propagate.
- Signing logic and core document workflow remain unchanged at v0.8.9.
