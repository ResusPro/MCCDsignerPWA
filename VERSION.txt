MCCDSigner PWA v0.8.2

Main release.

Changes from v0.8.1:
- signature section now explicitly confirms when a saved signature has been restored
- explains that the browser's “No file chosen” text refers only to choosing a replacement file in the current session
- no signing, detector or profile-persistence behaviour changed

v0.8.1 profile persistence retained:
- clinician profile stored in private local JSON (OPFS) where supported
- transparent PNG signature embedded in that JSON
- IndexedDB fallback/backup
- persistent storage requested where supported
- profile auto-save
