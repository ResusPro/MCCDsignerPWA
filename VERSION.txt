MCCDSigner PWA v0.8.1

Main release.

Changes from v0.8.0:
- clinician profile now persists to a private local JSON file (OPFS) where supported
- the JSON includes the transparent PNG signature itself
- IndexedDB remains as a fallback/backup
- persistent browser storage is requested where supported
- profile fields auto-save and also save when the app is hidden/closed
- visible version bump allows users to confirm the updated build is loaded

Existing v0.8 behaviour retained:
- validated detector/orientation/Medical Examiner box engine
- desktop Incoming / Signed / Archive workflow
- Android individual-PDF picker and Share workflow
- per-user filename initials
- signed filename format: <original>-<initials>signed.pdf
- automatic widening of narrow 90°/270° Medical Examiner boxes
